# EmailManager workshop pack

Business analysts each build their own EmailManager from a requirements document, with Claude doing the technical
work.

| File                                             | For                              | What it is                                                                                                           |
| ------------------------------------------------ | -------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| [COURSE_DESCRIPTION.md](./COURSE_DESCRIPTION.md) | Marketing                        | Title, description, learning objectives and outline                                                                  |
| [ATTENDEE_GUIDE.md](./ATTENDEE_GUIDE.md)         | Attendees                        | What to do before the day (about 45 minutes, mostly downloads) and on the day (paste one sentence)                   |
| [WORKSHOP_START.md](./WORKSHOP_START.md)         | Claude                           | Read first for each attendee: workshop defaults, two questions only, demo mailbox, one-step build from the templates |
| [check_mac.sh](./check_mac.sh)                   | Attendees (one paste) and Claude | Checks the Mac and installs Node and pnpm without a password                                                         |
| [FACILITATOR_GUIDE.md](./FACILITATOR_GUIDE.md)   | You                              | Team seats, preparation, agendas with timing checkpoints, fallbacks, snags                                           |
| [DRY_RUN_PLAN.md](./DRY_RUN_PLAN.md)             | You                              | Rehearse as an attendee with EmailManager_BA, time every phase and confirm the wording                               |

The pack builds on the [creator kit](../creator-kit/README.md): the playbook, the templates, the one-step scaffold
tool and the example requirements.
