# Creator kit

For turning business requirements into a running application with Claude, the way EmailManager was built.

| File                                                                             | For               | What it is                                                                                                                            |
| -------------------------------------------------------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| [NEW_PROJECT_PLAYBOOK.md](./NEW_PROJECT_PLAYBOOK.md)                             | Claude            | Step-by-step instructions with every technical decision already made. Claude asks you only for what it can't decide                   |
| [PLAYBOOK_STEPS_EXPLAINED.md](./PLAYBOOK_STEPS_EXPLAINED.md)                     | You (the Creator) | The same steps in plain language: what each achieves, and what you'll be asked                                                        |
| [EMAILMANAGER_BUSINESS_REQUIREMENTS.md](./EMAILMANAGER_BUSINESS_REQUIREMENTS.md) | You and Claude    | EmailManager's business requirements only (use cases, user stories, rules, decision tables, diagrams), ready to build another version |

## Start a new project

In Claude Code, in the folder where you keep projects, say:

> Read https://github.com/howardpodeswa/EmailManager/blob/main/docs/creator-kit/NEW_PROJECT_PLAYBOOK.md and start a new
> project from my requirements in `<path to your requirements file>`.

To build another EmailManager, point it at `EMAILMANAGER_BUSINESS_REQUIREMENTS.md` instead.
